# Design Assets & Mockups

This directory contains visual designs, mockups, design summaries, and reference screenshots for Catchingjobs:

- `catchingjobs-redesign.pen`: Pen visual design file.
- `catchingjobs-redesign.png` / `catchingjobs-redesign-preview*.png`: Rendered export previews of the redesign.
- `screenshot-catchingjobs.co.uk-*.png` / `screenshot-site-*.png`: Reference screenshots of original and current site implementations.
- `DESIGN_SUMMARY.md`: Summary and design tokens documentation for the Hallmark & Pen redesign.
