# CatchingJobs design files

Start with the **START HERE** board inside the appropriate file.

| File                                                                       | Purpose                                                                                                                                                                     |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [catchingjobs-website.pen](catchingjobs-website.pen)                       | Approved website pages, arranged in numbered desktop/mobile rows. The index identifies missing designs as **NEEDS DESIGN**. Use these pages for implementation comparisons. |
| [catchingjobs-design-system.pen](catchingjobs-design-system.pen)           | Foundations, reusable components, brand/account icons, illustrations and page patterns.                                                                                     |
| [catchingjobs-archive-2026-10-18.pen](catchingjobs-archive-2026-10-18.pen) | Complete snapshot from before cleanup, including earlier concepts and rejected directions. Keep this as recoverable history.                                                |

The website file retains local supporting component masters so its pages remain editable and its references resolve. The separate design-system file is a reference library; cross-file component edits are **not automatically synchronised**. Do not remove a supporting master just because its specimen also exists in the design-system file.

`refined-catchingjobs.pen` is the preserved original before separation. It is no longer the working page collection. Earlier `DESIGN_SUMMARY.md`, redesign PNGs and exploration folders are historical references, not approval for a new visual direction.

The approved Pencil pages are the visual source of truth; [design.md](../design.md) records implementation rules. The live application's routes, authentication, API contracts and data remain the functional source of truth.

`assets/` contains illustration assets and previews; `references /` contains source photography; `system/` contains earlier token/component exports. Check the current Pencil library before treating an older export as complete.
