## Architectural Synthesis for Catchingjobs

Across all 5 analyzed references, the strongest unifying high-craft patterns for job platforms are:
1. **H2 Split Diptych Hero**: A dominant left-side value proposition paired with a unified multi-parameter search dock (Role, Location, Category) and an active live job match preview stack on the right.
2. **Tabular Monospace Badges**: Salary figures (`£650–£850/wk`), location distances (`14.2 miles`), and match percentages set in monospace with `font-variant-numeric: tabular-nums`.
3. **F1 Asymmetric Bento Grid**: Replacing generic 3-column equal boxes with structured feature cards (salary trends, 1-click application status, certificate scanner, and live driver routing).
4. **Anti-Slop Restraint**: Zero purple/cyan decorative blobs, zero card-in-card visual noise, and zero fake testimonials.
